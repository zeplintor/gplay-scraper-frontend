Politique de Confidentialité

Dernière mise à jour : 17 janvier 2025

💡 En résumé : Nous collectons uniquement les données nécessaires au fonctionnement du service (email, clé de licence). Nous ne vendons jamais vos données et utilisons des services sécurisés (Stripe, Netlify, Render).

1. Introduction

PlayStore Analytics Pro s'engage à protéger la vie privée de ses utilisateurs. Cette politique de confidentialité explique quelles données nous collectons, pourquoi nous les collectons, et comment nous les utilisons.

En utilisant notre service, vous acceptez les pratiques décrites dans cette politique.

3. Données collectées

3.1. Données fournies directement

Nous collectons les données que vous nous fournissez :

  • Email : Pour l'envoi de la clé de licence et les communications importantes
  • Clé de licence : Pour l'authentification et l'accès aux fonctionnalités Premium
  • Nom (optionnel) : Si vous créez un compte

3.2. Données collectées automatiquement

  • Données de navigation : Type de navigateur, système d'exploitation, pages visitées (via Netlify Analytics - anonymisé)
  • Adresse IP : Collectée temporairement pour la sécurité (protection contre les abus)
  • Cookies de session : Pour maintenir votre connexion active

3.3. Données des analyses

  • Recherches d'applications : Les IDs des applications que vous analysez (non liées à votre identité)
  • Historique d'analyses : Stocké localement dans votre navigateur (LocalStorage)

3.4. Données que nous NE collectons PAS

  • ❌ Numéros de carte bancaire (gérés par Stripe uniquement)
  • ❌ Mots de passe (si système de compte ajouté, hashés avec bcrypt)
  • ❌ Données de tracking publicitaire
  • ❌ Données personnelles sensibles (religion, santé, etc.)

4. Utilisation des données

4.1. Finalités

Nous utilisons vos données pour :

  • Fournir le service : Authentification, accès aux fonctionnalités Premium
  • Traiter les paiements : Via Stripe (PCI-DSS compliant)
  • Envoyer la clé de licence : Par email automatique
  • Support client : Répondre à vos demandes
  • Améliorer le service : Analyses anonymisées d'utilisation
  • Sécurité : Détection d'abus et de fraudes

4.2. Base légale (RGPD)

  • Exécution du contrat : Fourniture du service payant
  • Consentement : Communications marketing (avec opt-out)
  • Intérêt légitime : Sécurité et amélioration du service

5. Partage des données

5.1. Prestataires tiers

Nous partageons vos données avec des prestataires de confiance :

  • Stripe : Traitement des paiements (certifié PCI-DSS Niveau 1)
  • Netlify : Hébergement frontend (USA, conforme RGPD)
  • Render : Hébergement backend API (USA, conforme RGPD)

5.2. Aucune vente de données

Nous ne vendons JAMAIS vos données à des tiers. Nous ne partageons vos données qu'avec les prestataires strictement nécessaires au fonctionnement du service.

5.3. Obligations légales

Nous pouvons divulguer vos données si requis par la loi (ordonnance judiciaire, réquisition).

6. Conservation des données

  • Données de compte : Conservées tant que votre licence est active
  • Données de paiement : Conservées par Stripe selon leurs politiques (généralement 7 ans pour conformité fiscale)
  • Logs serveur : 30 jours maximum
  • Après suppression de compte : Suppression sous 30 jours (sauf obligations légales)

7. Vos droits (RGPD)

Conformément au RGPD, vous disposez des droits suivants :

7.1. Droit d'accès

Vous pouvez demander une copie de toutes les données personnelles que nous détenons sur vous.

7.2. Droit de rectification

Vous pouvez demander la correction de données inexactes ou incomplètes.

7.3. Droit à l'effacement ("droit à l'oubli")

Vous pouvez demander la suppression de vos données personnelles.

7.4. Droit à la portabilité

Vous pouvez recevoir vos données dans un format structuré et lisible par machine.

7.5. Droit d'opposition

Vous pouvez vous opposer au traitement de vos données à des fins de marketing direct.

7.6. Exercer vos droits

Pour exercer ces droits, contactez-nous à : hello@playstore-analytics.pro

Nous répondons dans un délai de 30 jours maximum.

8. Sécurité des données

Nous mettons en œuvre des mesures de sécurité appropriées :

  • Chiffrement : HTTPS (TLS 1.3) pour toutes les communications
  • Stockage sécurisé : Données chiffrées au repos
  • Authentification : Clés de licence uniques et aléatoires
  • Accès restreint : Seuls les administrateurs autorisés ont accès aux données
  • Sauvegardes : Sauvegardes chiffrées régulières

9. Cookies

9.1. Cookies utilisés

  • license_key : Stocke votre clé de licence (session uniquement)
  • analysis_history : Historique de vos analyses (LocalStorage)

9.2. Désactiver les cookies

Vous pouvez désactiver les cookies dans votre navigateur, mais cela peut limiter certaines fonctionnalités du service.

10. Transferts internationaux

Nos prestataires (Netlify, Render, Stripe) sont situés aux États-Unis. Ces transferts sont encadrés par :

  • Les clauses contractuelles types approuvées par la Commission Européenne
  • Le EU-U.S. Data Privacy Framework (pour les prestataires certifiés)

11. Mineurs

Notre service n'est pas destiné aux mineurs de moins de 16 ans. Nous ne collectons pas sciemment de données de mineurs. Si vous pensez qu'un mineur a fourni des données, contactez-nous immédiatement.

12. Modifications de cette politique

Nous pouvons modifier cette politique de confidentialité à tout moment. Les modifications prennent effet dès leur publication sur cette page. Nous vous informerons des modifications importantes par email.
